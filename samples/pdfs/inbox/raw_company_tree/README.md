# Raw Company Tree Import

Kopiere hier deine aktuelle lokale Firmenstruktur 1:1 hinein, zum Beispiel:

```text
samples/pdfs/inbox/raw_company_tree/
  Alu-ONE/
  ENTHOLZER/
  KOCH/
  Muigg/
  Newo/
  REKORD/
  Rieder/
  SCHUCHTER/
  Schachermayer/
  Schlotterer/
```

Regel:
- Die aktuelle Struktur darf so bleiben, wie sie bei dir lokal ist.
- Ich sortiere danach in das Projekt-Zielschema um:
  - `regression/offers/<anbieter>/`
  - `candidates/offers/<anbieter>/`
  - `non_offer/auftrag_auftragsbestaetigung/<anbieter>/`
  - `non_offer/grafik_technik/<anbieter>/`

Nicht mitkopieren:
- doppelte Dateien, wenn du sie schon erkannt hast
- komplett irrelevante Mail-Container-Ordner ohne PDFs
